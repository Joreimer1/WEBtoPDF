Backend-val: Cloudflare vs GitHub Actions

Viktigt om Cloudflare Workers: Cloudflare Workers gratis-tier tillåter endast 128 MB RAM och max 10ms CPU. En riktig webbläsarmotor (som Chromium/Playwright) kräver minst ~500 MB RAM och 30–60 sekunder körtid. Cloudflare har en betallösning (Workers Browser Rendering), men den kostar från $5/månad.

Hur kör du backend 100% gratis utan betallösningar?

Alternativ 1: Lokalt på din dator Kör bara npm start i projektmappen. Då snurrar Express + Playwright lokalt och har direkt tillgång till Chromium, obegränsad RAM och nätverk. Snabbast och enklast!
Alternativ 2: GitHub Actions (Serverless Cloud) GitHub ger alla 2000 gratis minuter per månad på kraftfulla Ubuntu-servrar (7 GB RAM) med Playwright installerat. Du kan trigga crawlen direkt från ett GitHub Actions-workflow och ladda ner ZIP-filen därifrån!

Frontend-koden (den här sidan) kan du ladda upp direkt till ett GitHub-repository och aktivera GitHub Pages helt gratis.
